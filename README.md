# ArpiDent — онлайн-запись в стоматологическую клинику

Разработала учебное веб-приложение для записи пациентов на приём. В проекте есть публичная часть сайта, личный кабинет пациента, серверное API и отдельная страница администратора. Основной сценарий — выбрать услугу, врача и свободное время, оформить запись и затем просмотреть или изменить её статус.

## Возможности

- Каталог специалистов и стоматологических услуг.
- Просмотр доступных временных интервалов для выбранного врача.
- Запись на приём с проверкой занятости и прошедшего времени.
- Регистрация и вход пациента, просмотр своих записей.
- Отзывы с выбором врача и услуги.
- Отдельная админ-панель: список записей, поиск, фильтры и изменение статусов.
- Сохранение данных между перезапусками через локальный файл `db.json`.

## Технологии

JavaScript, HTML, CSS, Node.js, встроенный HTTP-сервер Node.js, JSON. Внешние npm-пакеты для запуска не требуются.

## Запуск

Понадобится установленный Node.js. В корне проекта:

```bash
npm start
```

Сайт доступен по адресу `http://localhost:3000`. Админ-панель расположена по адресу `http://localhost:3000/admin`.

Для другого порта можно задать переменную окружения `PORT` перед запуском.

## Структура

```text
public/
  index.html
  app.js
  style.css
  admin.html
  admin.js
server.js
database.js
db.json
package.json
README.md
```

`server.js` обрабатывает HTTP-запросы, проверяет данные записи и возвращает JSON. `database.js` читает и сохраняет данные, а файлы в `public/` отвечают за интерфейс.

## API

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/health` | Состояние сервера |
| GET | `/api/doctors` | Врачи |
| GET | `/api/services` | Услуги |
| GET | `/api/slots?doctorId=1&date=2026-12-15` | Доступное время |
| POST | `/api/bookings` | Создание записи |
| GET | `/api/bookings` | Список записей |
| PATCH | `/api/bookings/:id/status` | Изменение статуса |
| DELETE | `/api/bookings/:id` | Отмена записи |
| GET, POST | `/api/reviews` | Чтение и добавление отзывов |
| POST | `/api/users/register` | Регистрация |
| POST | `/api/users/login` | Вход пациента |
| POST | `/api/admin/login` | Проверка данных администратора |

## Как проверить

1. Запустить сервер и открыть `/api/health` — должен вернуться JSON с `ok: true`.
2. Открыть сайт, выбрать услугу и врача, затем запросить свободное время на будущую дату.
3. Оформить тестовую запись и проверить её в `/admin` и в `db.json`.
4. Попробовать занять тот же интервал повторно: сервер должен отклонить запись.
5. Изменить статус записи в админ-панели и проверить сохранение после перезагрузки страницы.

## Ограничения

Это учебный прототип. Хранение данных реализовано в JSON-файле, а механизм авторизации упрощён. Для работы с реальными пациентами необходимы защищённые сессии и права доступа, безопасное хранение паролей, полноценная база данных, резервное копирование и защита персональных данных. Сейчас приложение предназначено только для демонстрационных данных.
